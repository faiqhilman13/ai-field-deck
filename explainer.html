Cheat sheet

The same words from the video, in one place. Each card says what the thing is, then gives you a picture to remember it by.

AI model also called an LLM

The brain. A program that has read an enormous amount of text, so it can write, explain and reason.

Think of: a brilliant expert in a room with no phone.

Chatbot

An AI model you talk to in a chat window. It answers questions, but it can't do things for you.

Think of: passing notes through a mail slot.

Tool

One specific job the AI may ask for: search the web, check a calendar, send an email. Each comes with an instruction card.

Think of: a pair of hands for one task.

API Application Programming Interface

The official way one program asks another for something, using a fixed menu of requests and a key.

Think of: a waiter taking orders from a menu.

MCP Model Context Protocol

A shared standard for plugging services into AI apps. Build the plug once and any AI app that speaks MCP can use it.

Think of: USB-C, but for AI.

Connector

An MCP plug you switch on in your AI app's settings, such as Calendar or Email. Each one adds new tools.

Think of: plugging in a new appliance.

Harness

The app wrapped around the model. It passes on instructions, keeps notes, holds the tools, runs the steps and asks your permission.

Think of: the rest of the car around the engine.

AI agent

A model, inside a harness, with tools, working through a goal you set, one step at a time.

Think of: a capable assistant who gets it done.

The agent loop

Think about the next step, do it with a tool, check the result. Repeat until the job is finished.

Think of: how you'd tackle a chore yourself.

Good habits

  • Keep "ask before acting" on.Nothing gets sent, bought or deleted without your OK.
  • Connect only what you need.Each connector is a door into your things.
  • Check its work.AI can sound completely sure and still be wrong.
  • Never type passwords into a chat.Connectors use the real company's sign-in page instead.
